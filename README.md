Лабораторная работа №3 Git и PHP Cookies

Веб-приложение на PHP с авторизацией, регистрацией, сохранением настроек оформления в базе данных SQLite и передачей их через HTTP cookie. Реализована автоматическая авторизация.

Стек: 
* PHP 8.5
* SQLite
* Composer
* Git / GitHub


Установите зависимости автозагрузчика:
```bash
composer dump-autoload
Запустите встроенный сервер PHP: php -S localhost:8000

Откройте в браузере: http://localhost:8000
